# Images Folder

Add your images here with the following filenames:

## Required Images

1. **profile.png** (or .jpg, .jpeg, .webp)
   - Your profile picture
   - Used in the hero section
   - Recommended size: 400x400px or larger
   - Format: PNG, JPG, or WebP

2. **certificate-google-workspace.png** (or .jpg)
   - Google Workspace Certification
   - Used in the certifications section
   - Recommended size: 600x400px

3. **certificate-ai-workshop.png** (or .jpg)
   - AI Training Workshop Certification
   - Used in the certifications section
   - Recommended size: 600x400px

4. **certificate-sas-curiosity-cup.png** (or .jpg)
   - SAS Curiosity Cup 2025 Certificate
   - Used in the certifications section
   - Recommended size: 600x400px

## How to Add Images

1. Save your images with the exact filenames listed above
2. Place them in this `images` folder
3. Refresh your browser to see the images load

## File Extensions

You can use any of these formats:
- `.png`
- `.jpg` or `.jpeg`
- `.webp`
- `.gif`

Just make sure the filename matches what's listed above (e.g., `profile.png`, `profile.jpg`, etc.)

## Troubleshooting

- If images still don't show, clear your browser cache (Ctrl+Shift+Delete)
- Make sure filenames match exactly (case-sensitive on some systems)
- File size should be under 5MB for best performance
