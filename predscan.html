PredScan: Detecting Suspected Open Access Predatory Journals Using Machine Learning Model

2025 • Machine Learning / Predictive Analytics

Developed a machine learning-based approach for identifying suspected predatory open-access journals using classification and data analysis techniques. This project includes data collection, feature engineering on editorial and bibliometric indicators, model training and evaluation, and a prototype screening workflow to flag journals for further human review.

Highlights

  • Built classification models to separate suspected predatory journals from legitimate journals.
  • Engineered features based on editorial compliance, review times, and bibliometric signals.
  • Evaluated model performance using precision/recall and prioritized low false positive rates for reviewer efficiency.
